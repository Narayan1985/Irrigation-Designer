# Contributing / Contribuciones

## English
Contributions are welcome. Bug reports should include the QGIS and Python versions, operating system, complete traceback, CRS of the field and DEM, irrigation method, and reproducible steps.

Engineering contributions must document equations, assumptions, units, technical references, and validation cases. Please do not add undocumented agronomic or hydraulic constants.

## Español
Las contribuciones son bienvenidas. Los reportes de errores deben incluir versiones de QGIS y Python, sistema operativo, traceback completo, CRS del lote y DEM, método de riego y pasos reproducibles.

Las contribuciones de ingeniería deben documentar ecuaciones, supuestos, unidades, referencias técnicas y casos de validación. No se deben incorporar constantes agronómicas o hidráulicas sin documentar.
